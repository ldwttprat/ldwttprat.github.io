# lindseydewittprat.com

Personal site of Lindsey DeWitt Prat, PhD. Served by GitHub Pages.

- Pages are plain HTML, one folder per page (`/bio/index.html` etc.), shared design tokens inline.
- `assets/img/` holds all images; `assets/docs/` holds PDFs. No external dependencies.
- `content-archive/` is a raw HTML snapshot of the previous Squarespace site (July 2026), kept as the source for pages not yet rebuilt: POVs, Academia, Speaking, Translation, course subpages.
- Custom domain cutover pending: add CNAME file + DNS records when parity is reached.
